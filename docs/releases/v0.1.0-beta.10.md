# Runas-Codex v0.1.0-beta.10

Sobre a beta.9: sai a lista de calendário ao lado das datas na ficha do artigo.

- A data é escrita inteira no campo, com a sigla no fim: `3999-02-12 OC`. É só a sigla que escolhe o calendário,
  como na linha do tempo e nas propriedades.
- Ao gravar, o app confere se a sigla existe e se a data é válida nesse calendário. Data sem sigla é recusada com o
  aviso "Escreva a sigla do calendário no fim".

Windows `.exe`, Linux `.deb` e AppImage x64, com as somas em `SHA256SUMS.txt`.
